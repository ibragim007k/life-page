Управление сайтом

Ключ доступа нужно ввести один раз на этом устройстве — дальше он останется в браузере.

Дополнительные настройки

Где взять ключ доступа?
  1. Открой github.com/settings/personal-access-tokens/new
  2. В поле «Repository access» выбери «Only select repositories» → укажи этот репозиторий
  3. В «Permissions» → «Repository permissions» → «Contents» поставь «Read and write»
  4. Нажми «Generate token» и скопируй ключ — он покажется один раз
